# Para usted, mi amor

Una página para Yayani. Una espiral de letras «te amo» revela el retrato de Carlos y Yayani en 20 segundos y después muestra un mensaje.

## Abrir

Descargue `index.html` y ábralo en un navegador. El archivo incluye el retrato y funciona sin dependencias, instalación ni conexión a servicios externos.

## GitHub Pages

En el repositorio, abra **Settings → Pages**, seleccione **Deploy from a branch**, rama **main** y carpeta **/ (root)**, y guarde. GitHub mostrará el enlace cuando termine de publicar.

## Personalizar

El texto y los estilos están en `index.html`. La duración se define en la función `animate` (20000 milisegundos). El retrato está incluido como una imagen JPEG en una URL de datos en `photo.src`.

El botón permite iniciar y repetir la animación. Si el dispositivo solicita reducir el movimiento, el retrato aparece completo sin animación.

## Foto

Se utiliza la versión cercana sin sombreros que Carlos eligió. El retrato fue preparado mediante edición con IA de la foto proporcionada.
